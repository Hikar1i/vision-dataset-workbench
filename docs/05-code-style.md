# 代码规范

状态：适用于已批准的 Python/FastAPI 与 Vue 3/TypeScript 重构。

## 通用原则

- 优先实现当前已确认需求，避免为未来数据类型或部署方式预建通用框架。
- 一个模块只有一个清晰职责；页面、路由、领域规则、SQL、后台任务和文件操作不得重新集中到单个大文件。
- 让业务规则可独立测试，采样、状态转移和数据集划分等纯逻辑不得依赖 Web 请求或数据库连接。
- 对外部系统的调用集中到适配器；yt-dlp、FFmpeg、文件系统和任务执行器不渗入领域模型。
- 注释解释原因、约束和不直观行为，不复述代码。

## 后端约束

- Python 以 3.12 为运行基线，公共函数、应用服务和数据模型使用类型标注。
- HTTP handler 只负责输入、权限、应用服务调用和响应映射，不直接执行 SQL 或 shell 命令。
- 所有视频状态变更通过同一状态机入口；禁止在查询接口中修复状态或执行 DDL。
- 捕获具体异常并保留上下文。不得使用静默的宽泛 `except` 把部分失败伪装为成功。
- 跨数据库与文件系统的操作必须显式记录阶段，并提供幂等重试或补偿。
- 外部命令使用参数数组和受控环境，不拼接 shell 字符串；设置超时并记录退出码和受限日志。
- 所有文件引用先经过存储网关解析，验证解析后路径仍在配置根目录内。
- API 使用稳定枚举和带单位的字段名，不依赖前端猜测隐式默认值。
- 新 schema 只通过版本化迁移修改。
- API 不运行 FFmpeg、yt-dlp 或批量模型计算；这些操作只创建持久任务。单张交互式推理可在同步线程池运行，但只能返回待复核草稿，不得直接写入标注。
- 不使用 FastAPI 进程内 BackgroundTasks 承载可恢复长任务。

## 前端约束

- Vue SFC 使用 TypeScript；页面、资源客户端和任务状态按功能拆分。
- 页面负责组合功能模块，不直接散布 HTTP 请求和领域算法。
- API 调用集中在按资源拆分的客户端层，契约类型来自机器可读规范或由 CI 校验。
- 服务端资源、任务进度、表单草稿和纯视觉状态分开管理。
- 批量工作提交一个服务端命令或受控批量接口，不逐帧产生请求瀑布。
- 组件优先使用明确输入和事件；共享状态只服务于确实跨页面或跨功能的资源。
- 错误、空状态、加载、部分成功和权限不足必须具有独立 UI 表达。
- 保持键盘可达、可见焦点、语义标签和足够对比度。

## 工作台 UI 规范

所有登录后页面使用唯一 `AppShell`；页面不得自行复制品牌栏、退出入口或全局导航。项目详情再使用 `ProjectLayout` 提供项目身份和路由页签，业务页面只渲染自身工作区。

- 色板使用 Workbench Ink `#17212B`、Project Rail `#22303B`、Canvas `#F3F6F8`、Rule `#D5DDE4`、Process Teal `#16866F` 和 Signal Mint `#78D2B8`，统一定义在 `base.css` Token 中。
- 标题使用 Bahnschrift、Arial Narrow、Noto Sans SC；正文使用 Inter、Noto Sans SC、system-ui；ID、计数和技术信息使用等宽字体。不为该风格增加字体、图标或设计系统依赖。
- 页面间距优先使用 `base.css` 的共享尺寸令牌及其约 4px 基准倍数，局部间距可以取令牌缩放后的整数值。全局顶栏 62px，项目上下文栏 53px，资源列表工具栏 73px，侧栏展开/折叠宽度为 255/62px。
- 正文使用约 15px，辅助信息和表头使用 12–13px，常规控件高 37px，视频行至少 70px，缩略图为 79×46px；禁止使用 CSS `zoom`、整体 `transform: scale()` 或浏览器缩放模拟字号调整。
- ≥1200px 首次展开侧栏，768–1199px 首次折叠，<768px 使用 off-canvas；宽度偏好和一级菜单展开状态分别保存在浏览器本地。
- 一级菜单文字进入资源列表，箭头只控制最近资源；只显示已有真实路由的模块和页签。最近资源最多 5 项，当前项目优先，记录只保存在当前浏览器。
- 顶栏固定提供面包屑、任务中心和账号菜单。账号菜单使用 teleport 到 `body` 的浮层下拉，不得使用会参与顶栏文档流的原生 `details` 菜单。任务中心汇总当前用户可见项目的后台任务；最后查看后出现新终态任务时显示红点，已读时间只保存在当前浏览器。
- 品牌、一级导航图标、管理入口和用户头像共用 62px 固定图标轨道。侧栏展开或折叠只改变外壳列宽以及文字可见性，不得改变图标的水平中心、品牌字号或左右 padding。
- 项目上下文栏只显示短 ID、项目名、角色和已实现页签；项目描述放在项目设置，不恢复大面积项目介绍区。
- 页面只保留帮助用户定位或完成任务的信息。删除重复面包屑、装饰性英文标签和无操作价值的大段副标题。
- 每页最多一个填充主按钮。表格行操作采用同高、等宽、有边界的分段按钮；危险操作使用独立红色语义，不混入普通处理操作。
- 标签列表固定按启用状态、英文类别、中文描述、映射顺序、操作排列；映射顺序直接显示从 0 开始的 `sort_order`，上移、下移和删除集中在操作列。viewer 保留相同列结构，以禁用开关和只读文本展示，不隐藏可见信息。
- 标签新增栏使用“颜色、英文类别、中文描述、添加”的紧凑行布局，窄屏可换行。候选颜色使用高饱和、中等亮度的随机 HSL 色并有限次避让已有色相，不生成黑白灰；每项目候选色保存在 `sessionStorage`，选择颜色立即保存，成功添加后生成下一色，失败时保持原色。浏览器存储不可用时只回退到当前页面内存，不新增持久化依赖。
- 视频身份列使用 79×46px 缩略图，标题和文件名单行省略并提供完整 `title`。规格、帧数、媒体状态和状态信息各自成列，不把多个概念塞入一个宽列。
- 页面工具栏与列表之间保留约 48px 固定动作区；未选择时显示数量，选择后在原位置显示批量操作。短期成功/失败使用浮层消息，阻断加载错误在正文显示，禁止 alert 或批量栏推动列表起始位置。
- 状态信息只由结构化 Video、Task 和 SamplingSummary 数据推导，展示字符串不得反向决定权限、按钮状态或任务参数。备注和自由文本 `status_info` 不恢复。
- Checkbox、Switch、Button 和 Select 使用真实语义控件，支持键盘、可见 `:focus-visible` 和明确可访问名称。全选必须表达未选、半选和全选，且只影响当前已加载的可操作记录。
- 桌面表格保留可读最小宽度并水平滚动；窄屏不把九列压缩成不可识别内容。
- 视频停用行可以降低对比度，但播放、采样配置、抽帧和帧管理是否可用仍由权限、媒体状态和采样状态分别决定，不能把 `enabled` 当作总禁用开关。
- 面向用户的帧管理操作统一称为“筛帧”；数据库实体、TypeScript 类型和 API 资源仍使用稳定技术名称 `Frame`，不得为展示文案机械改名。
- Element Plus 常规/快速过渡保持其原生 `300/200ms` 节奏；Dropdown、Drawer 和 Dialog 使用内建动效并通过 `append-to-body` 避免被工作区滚动容器裁剪。侧栏列宽使用约 240ms，侧栏文字使用约 180ms；页面和项目页签进入使用约 240ms、离开使用约 160ms，位移不超过 8px。常规按钮可以在 hover 时上移 1px、active 时缩放到 0.98，文本、链接和禁用按钮不得移动。不得为普通页面切换增加大幅平移、缩放或弹跳。
- 尊重 `prefers-reduced-motion`，减少动态偏好下将过渡缩短到近乎无动画；颜色不能成为状态的唯一表达方式。

## 在线标注工作台规范

- 标注使用独立焦点路由和全屏固定工作台，不嵌套项目页普通滚动区。布局固定为顶部推理栏、左侧工具栏、中央画布、右侧信息栏和底部缩略图轨道；缩略图下对齐，对象列表优先获得右栏剩余高度。
- 工具栏、推理参数、帧状态、对象列表和缩略图轨道预留稳定尺寸。加载、批量任务、对象展开、提示消息和按钮状态不得改变主画布的起点或使控制项漂移。
- 画布以原图像素坐标保存矩形；缩放和平移只影响视图变换。不得把屏幕坐标、CSS 尺寸或当前缩放比例写入标注 API。
- 手动编辑支持绘制、选中、移动、四角缩放、删除、撤销和重做。快捷键不得在输入框、下拉搜索框或可编辑元素中触发；按住 Space 的临时拖拽模式在松开和失焦时都必须复位。
- 标注草稿只在切换帧、点击其他缩略图或关闭工作台时保存。意外离开仅警告，不引入定时自动保存或逐操作请求。
- 单张自动标注只替换当前浏览器草稿，用户确认后随正常保存链路提交。批量自动标注运行时整段视频工作台只读，保留浏览、缩放和查看能力，并稳定显示任务状态。
- viewer 的视频“标注”按钮显示为禁用，不通过进入后再报错表达权限；后端仍必须独立拒绝其写请求。
- 缩略图轨道当前帧必须保持高亮并自动滚动到可见区域；全帧网格覆盖层点击目标帧后立即收起。覆盖层不得改变底层固定布局尺寸。
- 支持 `prefers-reduced-motion`，但选择框、画布变换和面板开合的反馈仍需清晰；动画不得延迟保存、权限或任务状态变化。

## 命名与数据表达

- 领域名称在数据库、API、后端和前端保持一致；同一概念不同时出现 `enabled`、`is_used` 等近义字段。
- ID 是稳定身份，不承载文件路径、列表位置或可变显示名称。
- 时间统一为 UTC，持续时间、帧率、字节数等字段明确单位。
- 任务运行状态与视频业务状态使用不同类型。
- `Unknown` 只用于文档中的未决事实，不作为运行时兜底值。

## 规模与拆分

不设机械行数上限，但出现以下情况时应拆分：

- 文件同时处理 UI、网络、业务规则和持久化中的多个层级。
- 修改一个功能需要理解无关流程。
- 测试只能通过启动整个应用执行。
- 同一状态、API 路径或辅助函数出现重复定义。

拆分应围绕业务职责，而不是建立只有转发作用的抽象层。

## 工具与自动检查

当前仓库检查命令：

```bash
cd backend && uv run ruff check src tests alembic
cd backend && uv run pytest
cd frontend && npm test
cd frontend && npm run build
```

后端 Ruff、pytest 配置位于 `backend/pyproject.toml`；前端 TypeScript 检查由 `vue-tsc` 随生产构建执行。当前没有额外前端 lint 工具，不为重复能力增加依赖。
