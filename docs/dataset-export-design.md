# 数据集导出与数据集管理设计

状态：已批准，待实施。

## 目标与范围

- 从项目中已启用的视频和采样帧生成可训练、可追溯的 YOLO 数据集。
- 导出时冻结类别映射、标注、视频划分和统计快照；后续项目修改不影响既有导出。
- 复用持久化任务系统执行导出，避免阻塞 API 和前端页面。
- 提供项目级数据集列表、详情、下载和逻辑删除。
- 不恢复遗留系统通过 `dataset_conf.yaml` 反向修改项目配置的功能，也不输出采样帧启停位图。

## 数据模型与目录

新增项目级 `DatasetExport` 记录，保存：

- 导出 UUID、项目、创建者及关联任务。
- 展示名称、状态、输出路径和错误信息。
- 期望及实际训练/验证比例。
- 总帧数、训练帧数和验证帧数。
- 类别映射快照 JSON。
- 视频划分和逐视频统计 JSON。
- 创建、开始、完成和逻辑删除时间。

列表常用值使用普通字段；只在详情中读取的类别、划分和统计保存在 JSON 中。本阶段不增加导出类别或导出视频明细表。

数据库和 API 始终使用导出 UUID。正式目录使用便于人工定位的名称：

```text
projects/<project UUID>/exports/<安全化数据集名称>_YYYYMMDDHHMMSS/
```

目录名保留中文、英文、数字、空格、连字符和下划线；斜杠、反斜杠、控制字符等替换为下划线，去除首尾空格和句点，安全化名称最长 80 个字符。时间使用服务器本地时区。若同名导出在同一秒冲突，依次追加 `_2`、`_3`。展示名称允许重复，导出完成后不提供重命名。

任务先写入以导出 UUID 命名的临时目录，校验成功后原子发布到正式目录。输出结构为：

```text
<数据集名称>_YYYYMMDDHHMMSS/
├── train/
│   ├── images/
│   └── labels/
├── val/
│   ├── images/
│   └── labels/
├── dataset.yaml
├── classes.txt
└── manifest.json
```

图像使用硬链接，标签使用 YOLO 文本格式。导出文件名沿用现有全项目唯一的 `<video short code>_frame_<六位序号>`，避免平铺到同一集合后重名。每张图像都生成同名标签文件；没有保留标注框的图像生成空文件并作为负样本。

## 类别快照

导出弹窗不再提供类别文本文件或手工类别输入。类别有两种配置方式：

1. 默认使用项目标签管理中的当前顺序和启停状态。
2. 手动编辑当前快照，只允许启停类别以及上移、下移；不允许新增、删除或重命名。

快照为每个类别保存来源标签 UUID、英文名称、映射序号和启用状态。任务创建后快照不再受项目标签变化影响。

映射序号取完整快照列表的位置并从 0 开始。停用类别保留其映射槽位，只过滤该类别的标注框，不压缩其他类别序号。移动任何类别后，完整列表按照新顺序重新编号。例如：

```text
0 person  停用
1 cat     启用
2 dog     停用
3 car     启用
```

`classes.txt` 与 `dataset.yaml` 保留全部四个类别和完整映射，YOLO 标签文件只会出现类别编号 1 和 3。原本只包含 person 或 dog 标注的图像仍导出，并生成空标签文件。至少必须启用一个类别，否则拒绝创建导出。

## 参与范围与数据冻结

仅导出满足以下条件的数据：

- 视频处于启用状态。
- 采样帧处于启用状态。
- 标注框所属类别在本次导出快照中启用。

没有启用采样帧的视频不参与划分，并在清单中记录原因。停用视频及其统计同样写入清单，但不生成样本。

创建导出的事务捕获参与视频、采样帧及其修订号，并保存类别映射和导出参数。任务进入终态前，能够改变这些视频源数据的写操作返回 409，包括视频或帧启停、重新抽帧、手动标注和自动标注；读取不受影响。由此无需把大量标注框复制进数据库快照，也能保证 Worker 读取到创建任务时的稳定数据。新增视频和项目标签后续变化不影响已经保存的参与范围和类别快照。

源图像被系统外部删除或替换、修订号异常或文件内容不可读取时，任务整体失败并提示重新导出，不静默跳过文件。任务成功、失败或取消进入终态后自动解除写入冻结。

## 训练集与验证集划分

比例范围为 `[0, 1]`，输入值表示训练集目标比例：

- 训练集比例为 0：全部有效视频进入验证集，训练集为空。
- 训练集比例为 1：全部有效视频进入训练集，验证集为空。
- 比例处于 `(0, 1)`：有效帧数大于 1000 的视频固定进入训练集，其余视频参与确定性贪心划分。

普通比例下先按有效帧数从多到少排列小视频，相同帧数按视频 UUID 排列。逐个比较将视频加入验证集是否能使验证帧数更接近目标；能则加入，否则进入训练集。同一视频永远不会跨集合，算法不使用随机数。实际比例可能因视频级划分和大视频规则偏离期望值，列表和详情同时展示期望比例与实际比例。

划分和统计均以导出时启用的视频及启用采样帧为基准，包括没有任何保留标注框的负样本帧。

## 任务与错误处理

新增 `export_dataset` 任务类型，状态沿用 `queued`、`running`、`succeeded`、`failed`、`canceled`。导出记录面向业务显示 `queued`、`running`、`ready`、`failed` 和 `canceled`，并关联任务错误。

同一项目同时只允许一个导出任务处于排队或运行状态。不同项目的任务继续由现有 Worker 调度。任务负责：

1. 读取已冻结快照并创建临时目录。
2. 按划分结果硬链接图像并生成 YOLO 标签。
3. 写入 `dataset.yaml`、`classes.txt` 和 `manifest.json`。
4. 校验文件数量、标签类别范围和统计结果。
5. 原子发布正式目录并把导出状态改为 ready。

取消或失败时清理临时目录，不发布残缺产物。硬链接失败、源文件缺失、快照无效或发布冲突均使任务失败，不自动退化为复制文件。

## API 与权限

新增接口：

```text
POST   /api/v1/projects/{project_id}/dataset-exports
GET    /api/v1/projects/{project_id}/dataset-exports
GET    /api/v1/projects/{project_id}/dataset-exports/{export_id}
GET    /api/v1/projects/{project_id}/dataset-exports/{export_id}/download
DELETE /api/v1/projects/{project_id}/dataset-exports/{export_id}
```

创建接口接收展示名称、训练集比例和类别快照。服务端重新校验：

- 项目标签 UUID 与英文名称匹配。
- 映射序号从 0 开始、连续且不重复。
- 至少存在一个启用类别。
- 训练集比例位于 `[0, 1]`。
- 安全化后的数据集名称不为空。
- 项目至少存在一个可导出的启用采样帧。

owner 和 editor 可以创建、查看、下载和删除；viewer 只能查看和下载。正在运行的导出不能删除，需要先在任务中心取消。

## 前端交互

原始数据页在“导入视频”右侧增加“导出数据集”。导出聚焦模态框包含：

- 数据集名称输入框。
- 训练集比例 Slider 和可输入数值框。
- 与训练集比例同步、只读的验证集比例。
- “使用项目标签”与“手动调整快照”两种类别模式。
- 手动模式下的类别启停、映射序号、英文类别、上移和下移操作。
- 预计参与导出的启用视频数和启用帧数。
- 取消与开始导出按钮。

项目页签顺序为：原始数据、标签管理、数据集管理、项目设置。

数据集管理列表展示名称、状态、导出时间、类别摘要、总帧数、训练帧数、验证帧数、期望比例、实际比例，以及详情、下载、删除操作。

详细信息使用全屏模态框：上部展示基础信息和类别快照，下部使用可滚动表格展示每个视频的所属集合、总帧数、启用帧数、停用帧数、正样本数和负样本数，并提供折叠的 `manifest.json` 原文。

## 下载与逻辑删除

下载接口按请求流式生成 ZIP，图片使用不压缩存储，避免在工作区长期保存额外的完整压缩包。请求断开后停止打包。本阶段不提供断点续传。

删除数据集时保留数据库记录并设置删除时间，将目录移动到：

```text
<workspace>/.deleted/projects/<project UUID>/exports/<导出目录名>/
```

正常列表不再返回已删除记录。本阶段不提供回收站或恢复界面；该目录结构同时为后续整个项目的逻辑删除预留统一位置。

## 验证范围

后端测试覆盖：

- 训练比例 0、1 和普通比例。
- 大视频固定训练及极端比例优先级。
- 视频级确定性贪心划分及重复执行稳定性。
- 稀疏类别映射、停用类别过滤和空标签负样本。
- 图像硬链接、YOLO 标签、配置文件和目录结构。
- 缺失源文件时整体失败及临时目录清理。
- 活动导出期间参与视频的相关写入被冻结，终态后解除。
- 名称安全化、同秒重名和原子发布。
- viewer 权限、流式下载和逻辑删除。

前端测试覆盖：

- 比例控件双向同步及边界值。
- 默认类别快照和手动启停、排序。
- 无启用类别时阻止提交。
- 列表状态、详情、下载、删除及角色可见性。
