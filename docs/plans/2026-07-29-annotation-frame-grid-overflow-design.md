# 全部采样帧网格溢出修复设计

状态：待用户复核
日期：2026-07-29

## 问题

标注工作台的“全部采样帧”覆盖层使用固定高度网格区域，但网格隐式行和外层卡片没有明确的 16:9 高度约束。帧数较多时浏览器会压缩隐式行；卡片的 `overflow: hidden` 随后裁掉缩略图底部，导致帧序号和启停状态不可见。时间戳仍位于顶部，因此没有被裁掉。

## 修复

- 保留现有覆盖层、数据加载方式和原生纵向滚动，不增加分页、加载更多或新接口。
- 全部帧网格设置 `min-height: 0` 和内容高度隐式行，确保它作为固定覆盖层的可滚动区域。
- 网格直接子按钮固定为 16:9，不允许行轨道压缩；超出视口的帧通过既有 `overflow: auto` 查看。
- 标题栏保持固定，缩略图宽度、时间戳、编号、启停状态、遮罩和标注预览样式不变。

## 验证

- 组件测试锁定全部帧卡片的专用类，避免以后移除固定比例约束时无结构提示。
- 运行完整前端测试和生产构建。
- 更新前端规范，明确全帧网格必须滚动，禁止为了单屏容纳全部帧而压缩卡片。
