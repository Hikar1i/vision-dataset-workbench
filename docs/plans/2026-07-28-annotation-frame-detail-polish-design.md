# 标注与筛帧细节优化设计

状态：已实施
日期：2026-07-28

## 范围

本次只统一标注工作台与筛帧工作台已有展示和交互，不改变标注保存、筛帧草稿、权限或自动标注任务链路，不新增前端依赖。

## 标注框标题

- 标注主画布和筛帧大图把标题放在矩形框外侧左上方，使框内保持完整矩形区域。
- 标题格式为 `{英文类别} #{全局序号}`；模型标注且存在置信度时追加 ` · {置信度}`，置信度保留两位小数，例如 `helmet #3 · 0.92`。
- 手动标注不显示置信度。判断依据为既有 `source === "model"` 和非空 `confidence`，无需修改数据库或完整标注接口。
- 图片顶部的标题允许绘制到图像外的工作区；工作区边界仍可正常裁切，不把标题强制塞回矩形内部。

## 缩略图统一

标注横向序列、标注全部帧网格和筛帧网格复用同一缩略图展示规则：

- 16:9、`#111820` 背景、图片 `object-fit: contain`。
- 右下角显示 `#{采样帧序号}`。
- 右上角显示 `m:ss.SSS` 采样时间；超过一小时继续累计分钟，例如 `65:02.462`。
- 左下角始终显示绿色“已启用”或红色“已停用”；停用帧叠加透黑遮罩。
- 缩略图标注预览只显示细类别色矩形框，不显示类别、序号或置信度文本。

筛帧工具栏增加“缩略图标注”开关，默认开启。状态只存放在当前挂载组件的前端内存中：切换视频或重新打开对话框时沿用，页面刷新后恢复默认开启。关闭开关只隐藏标注 SVG，不清除已加载数据或发起新请求。

## 标注预览数据与性能

筛帧页面复用现有帧列表 `include_annotations=true` 参数和 `FrameAnnotationThumbnail` SVG 预览，不新增逐帧请求或专用接口。后端按每页最多 200 帧一次查询标注预览；标注页面已经使用相同链路。

常规数百至数千帧场景可直接使用。单视频数万帧并选择“全部”时，缩略图数量本身已是主要 DOM、图片解码和 SVG 开销，本次不引入虚拟列表或额外缓存层；出现可测量卡顿后再单独优化。

## 标题与按钮

- 筛帧标题改为 `VDM / FRAMES`，高度、左侧间距、颜色、等宽字体和字距对齐标注焦点页的 `VDM / ANNOTATION`。
- 标注页“单张运行”“批量运行”“标注统计”使用与筛帧“保存更改”一致的绿色主操作样式，并保留各自禁用状态。
- 筛帧工作台内取消按钮、缩略图卡片在 hover/active 时的位移和缩放，只保留颜色、边框和阴影反馈。全局其他页面继续沿用既有微动效。

## 测试与文档

- 组件测试覆盖模型/手动标注标题、框外位置配置和置信度格式。
- 缩略图组件测试覆盖统一时间格式、启用/停用状态、遮罩、序号和标注框显隐。
- 筛帧组件测试覆盖默认开启、内存切换和 `include_annotations` 请求。
- 更新 `docs/05-code-style.md` 和 `docs/06-testing-strategy.md` 中的筛帧与标注规范。
