# 训练任务数据集选择摘要调整设计

状态：设计已确认，等待书面规格复核。

## 1. 目标与范围

本次只调整新建/编辑训练任务页的数据集选择信息展示与模型级模式交互，不修改训练 API、数据库、多数据集映射契约或训练数据准备流程。

目标是让任务默认数据集与模型自定义数据集使用同一套摘要语言，解决当前多数据集信息过少、单数据集缺少统计、模型级操作冗余和映射按钮位置不准确的问题。

## 2. 组件边界

新增轻量展示组件 `DatasetSelectionSummary.vue`，接收当前模式对应的数据集资源和可选多数据集配置，只负责：

- 渲染单数据集统计和类别 chips；
- 渲染多数据集数量、图像数量、数据集 chips、目标类别数量和类别 chips；
- 分别管理数据集 chips 与类别 chips 的两行折叠状态；
- 在多数据集模式内提供配置映射入口。

任务编辑页和模型编辑器继续拥有选择模式、资源 ID、映射配置与弹窗状态。摘要组件不修改训练草稿，也不打开弹窗，避免产生第二套状态来源。

## 3. 任务总体设置

### 3.1 单数据集

- 下拉框初始值保持 `null`，不自动选择任何数据集。
- placeholder 固定为“未选择任何数据集”。
- 未选择时不显示虚假的数量或类别信息。
- 选择后在下拉框下显示：
  - `X 张图像 · N 个类别`；
  - 按来源索引排序的类别 chips，格式为 `索引 : 类别名`。
- 类别 chips 使用浅灰背景、边框和圆角矩形；长类别名单行省略，并通过 `title` 提供完整内容。

### 3.2 多数据集

摘要卡按下列顺序显示：

1. `N 个数据集 · X 张图像`；
2. 数据集 chips，格式为 `数据集项目名称 / 数据集名称`，最多两行；
3. 超出两行时显示“…”按钮，可展开或收起全部数据集 chips；
4. `N 个目标类别`；
5. 类别 chips，格式为 `索引 : 类别名`，最多两行；
6. 超出两行时显示独立“…”按钮，可展开或收起全部类别 chips。

“配置映射”或“开始配置”按钮位于多数据集摘要卡右上角。没有有效配置时保留警示边框和空状态说明，但仍按相同结构呈现入口。

## 4. 模型具体设置

模型数据集模式文案统一为：

- `继承任务默认`；
- `单数据集`；
- `多数据集`。

删除“恢复任务默认”按钮；用户直接选择“继承任务默认”即可恢复继承语义。

模式切换只改变 `dataset_mode`，不清空休眠的 `dataset_export_id` 或 `multi_dataset_config`。用户切回单数据集或多数据集时恢复上一次保存值，延续现有“停用不删除配置”规则。

- `inherit`：显示任务默认数据集的只读摘要，不显示映射按钮。
- `single`：显示下拉框和与任务总体设置完全一致的单数据集统计与类别 chips。
- `multi`：显示与任务总体设置完全一致的多数据集摘要卡；映射按钮只在卡片内出现。

首次切换到模型多数据集且没有模型配置时，继续以任务默认多数据集配置作为弹窗工作副本；取消时回到单数据集，保存后形成独立模型配置。

## 5. 视觉与交互约束

- 延续现有工业工作台配色、字体、圆角和设计令牌，不引入新依赖或新色板。
- chips 使用中性浅灰底色与边框，数据集和类别仅通过内容层级区分，不增加高饱和装饰色。
- 所有正文和可点击文字不低于 14px。
- 两行折叠以容器实际高度约束，不按固定 chip 数量截断，适配 1920×1080 与 2560×1440 的不同可用宽度。
- 两组“…”按钮分别提供 `aria-expanded`、`aria-controls` 和可访问名称；展开/收起使用 240–280ms，高度与透明度平滑过渡。
- `prefers-reduced-motion: reduce` 下关闭展开动画，但状态仍立即可见。
- 下拉框、摘要卡和模型卡不能产生页面级横向滚动；长项目名、数据集名和类别名必须省略，不得挤占相邻内容。

## 6. 数据与错误处理

所有统计从已加载的 `TrainingResources.datasets` 推导：

- 图像数使用 `total_frames`；
- 类别数和类别 chips 使用 `labels`，按 `index` 排序；
- 多数据集目标类别 chips 使用 `target_classes` 的数组位置作为最终索引；
- 配置中引用但资源接口不再返回的数据集不生成伪造 chip，摘要数量以实际可用资源为准，并保持现有配置无效提示。

本次不增加网络请求。资源加载失败继续由训练任务编辑页现有错误处理负责。

## 7. 验收

自动化测试至少覆盖：

- 单数据集空值 placeholder；
- 单数据集图像数、类别数和按索引排序的 chips；
- 多数据集两层统计和两组 chips；
- 两组折叠按钮的独立状态和 ARIA；
- 模型模式新文案；
- 继承/单数据集模式不渲染映射按钮，多数据集模式才渲染；
- 删除冗余“恢复任务默认”按钮且切换继承仍正确更新模式。

Chrome 验收覆盖 1920×1080 与 2560×1440：任务默认单/多数据集、模型 inherit/single/multi、超长 chips、省略、展开收起、hover/press/focus、reduced-motion 和页面横向溢出。最终由独立 `ui_ux_reviewer` 只读复核；存在 Blocking 时不得写入 `UI/UX REVIEW PASSED`。
