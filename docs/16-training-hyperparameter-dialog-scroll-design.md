# 训练超参数弹窗内部滚动设计

## 目标

训练任务的完整超参数弹窗必须完整限制在浏览器视口内。附加参数过多时，仅左侧表单纵向滚动；标题、右侧 RAW/YAML 面板和底部操作区保持可见。

## 方案

仅调整 `TrainingHyperparameterDialog.vue` 的弹窗专用样式：

- 保留现有最大宽度 `1400px`，给弹窗设置视口内高度并使用纵向 Flex 布局。
- 弹窗正文占据标题和底部操作区以外的剩余空间，并禁止正文自身滚动。
- 两栏编辑器占满正文高度；左侧 `.form-pane` 使用 `overflow-y: auto`。
- 右侧 `.raw-pane` 不产生面板级滚动，RAW 文本过长时继续由 textarea 自身滚动。
- 不修改可复用的 `HyperparameterConfigEditor.vue`，避免改变超参数模板独立编辑页。

## 验收

- 在常规桌面视口中，弹窗标题、正文和底部按钮均完整可见，页面与弹窗正文没有纵向滚动条。
- 左侧附加参数超过可用高度时，左栏出现纵向滚动条并可访问全部参数。
- 滚动左栏不会移动右侧 RAW/YAML 面板或底部按钮。
- 现有超参数编辑、校验和提交行为不变。
